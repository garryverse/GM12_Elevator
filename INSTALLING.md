## Install Instructions

Folow these simple steps to elevate your life:
1. Download [Garry's Mod 12](https://dl.flatgrass.net/data/gmod12-flatgrass.7z)
2. Download the [repository](https://github.com/garryverse/GM12_Elevator/archive/refs/heads/main.zip)
3. Extract both the addon and the gamemode to their proper locations:
    - `addons/elevator` goes into `garrysmod/addons/`
    - `gamemodes/Elevator` goes into `garrysmod/gamemodes/`
4. Launch Garry's Mod 12 and Select "Start New Game".
5. Select elevator in the Other maps category.
 Then select the **small wrench icon** in the top right of that menu.

</div>

6. Select 'Elevator' in the default dropdown box under the gamemode category.

<div style="text-align: center;" align="center" style="display: block; margin: 0 auto">
    <img width="750px" height="750px" src="./_guide_imgs/install2.jpg?raw=true" draggable="false" />

7. Hit Start Singleplayer if you want a solo game, or Start Multiplayer if you want to host a server!
8. *Enjoy the experience of an elevator!*
